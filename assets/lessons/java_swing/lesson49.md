## 49: Database 101 - What is a Database & SQLite?

ႁူမ်ၸူမ်းႁပ်ႉတွၼ်ႈၸူး Module 8 ၶႃႈ! ပေႃးဝႃႈ လုၵ်ႈႁဵၼ်းသူၸဝ်ႈ ပႆႇယၢမ်ႈတႅမ်ႈ Code ၵဵဝ်ႇလူၺ်ႈ Database မႃးသေပွၵ်ႈ၊ 
Lesson ၼႆႉ တေပဵၼ်လွင်ႈပိုတ်ႇၽၵ်းတူ ၵႂႃႇၸူး လုမ်ႈၾႃႉ ၶွင်လွင်ႈၸတ်းၵၢၼ်ၶေႃႈမုၼ်း ၸၼ်ႉပရူဝ်ႇ (Professional) ၶႃႈ။

### 1. Database (တိူၵ်ႈၶေႃႈမုၼ်း) ပဵၼ်သင်?

ၼႂ်း Module 7 ၼၼ်ႉ ႁဝ်းလႆႈသိမ်းၶေႃႈမုၼ်း သႂ်ႇၼႂ်းၽၢႆႇ `.txt` လႄႈ `.csv` ၵႂႃႇယဝ်ႉၶႃႈ။ 
ၽၢႆႇၸိူဝ်းၼၼ်ႉ မၼ်းလီတွၼ်ႈတႃႇ ၶေႃႈမုၼ်းဢိတ်းဢွတ်းယူႇ၊ ၵူၺ်းၵႃႈ ပေႃးၶေႃႈမုၼ်းႁဝ်း မီးမႃးပဵၼ် **သႅၼ်ထႅဝ်** လူး?

* **လွင်ႈႁႃ (Search):** ဢၢၼ်ႇၽၢႆႇ CSV တင်းသဵင်ႈ တေၸႂ်ႉၶၢဝ်းယၢမ်းႁိုင်တႄႉတႄႉ။
* **လွင်ႈမႄး (Update):** တွၼ်ႈတႃႇမႄးၶေႃႈမုၼ်း ၵေႃႉလဵဝ် ၼႂ်းၽၢႆႇ CSV ၼၼ်ႉ ယၢပ်ႇယဵၼ်း လႄႈ ၸၢင်ႈၽိတ်းပိူင်ႈလႆႈငၢႆႈ။

**Database** ၼႆႉ မၼ်းမိူၼ်ၼင်ႇ "တိူၵ်ႈသိမ်းၶေႃႈမုၼ်း ဢၼ်မီးလွၵ်းလၢႆးၸတ်းၵၢၼ် လီသုတ်ႉ" ၶႃႈ။ 
မၼ်းၸၢင်ႈႁႃၶေႃႈမုၼ်း လႆႈဝႆး မိူၼ်ၾႃႉမႅပ်ႈ (Milliseconds)၊ လႄႈ ၸၢင်ႈမႄးလႅၵ်ႈလၢႆႈ ဢမ်ႇၼၼ် မွတ်ႇပႅတ်ႈ ၶေႃႈမုၼ်းလႆႈတႅတ်ႈၼႅတ်ႈ ဢမ်ႇမီးလွင်ႈလေႃးလႄးၵၼ်ၶႃႈ။

### 2. Relational Database (RDBMS)

Database ဢၼ်ႁဝ်းတေၸႂ်ႉၼႆႉ ႁွင်ႉဝႃႈ **Relational Database** ၶႃႈ။ မၼ်းသိမ်းၶေႃႈမုၼ်းပဵၼ် "လွၵ်းသဵၼ်ႈမၢႆ" ဢၼ်ႁွင်ႉဝႃႈ **Table** ၶႃႈ (မိူၼ်ၼင်ႇ လွၵ်းၼႂ်း Excel ၼၼ်ႉယဝ်ႉ)။

ပိူင်ယၢင်ႇ Table `students`:

| id (Primary Key) | name | course | phone_number |
| --- | --- | --- | --- |
| 1 | Sai Mao | Java Swing | 09-123456789 |
| 2 | Kham | Flutter | 09-987654321 |
| 3 | Ying | Python | 09-111222333 |

ၼႂ်း Table ဢၼ်ၼိုင်ႈ တေမီး ၶေႃႈမုၼ်း 3 လွင်ႈ:

* **Columns:** မၵ်းမၼ်ႈဝႃႈ ႁဝ်းတေသိမ်း ၶေႃႈမုၼ်းသင်။ (ပိူင်ယၢင်ႇ: `id`, `name`, `course`)။
* **Rows:** ၶေႃႈမုၼ်း ၶွင်ၵူၼ်းၵေႃႉၼိုင်ႈ ဢမ်ႇၼၼ် ၶူဝ်းၶွင်ဢၼ်ၼိုင်ႈ။
* **Primary Key:** မၢႆလၢၵ်ႇလၢႆး ဢၼ်ဢမ်ႇမိူၼ်ၽႂ် ၼႂ်း Table (ပိူင်ယၢင်ႇ: မၢႆၶပ်ႉ `id` 1, 2, 3...)။ ၼႆႉလမ်ႇလွင်ႈတႄႉတႄႉ တွၼ်ႈတႃႇဢမ်ႇႁႂ်ႈ ၶေႃႈမုၼ်း သွၼ်ႉထပ်းၵၼ် သေ ၸၢင်ႈၸီႉမွၵ်ႇလႆႈ တႅတ်ႈတႅတ်ႈၼႅတ်ႈၼႅတ်ႈဝႃႈ ႁဝ်းတိုၵ်ႉလၢတ်ႈထိုင် ထႅဝ်လႂ်။

### 3. ပဵၼ်သင်လႄႈ ႁဝ်းလိူၵ်ႈၸႂ်ႉ SQLite?

Database ၼႂ်းလုမ်ႈၾႃႉၼႆႉ မီးလၢႆမဵဝ်းတႄႉတႄႉ မိူၼ်ၼင်ႇ MySQL, PostgreSQL, Oracle လႄႈ SQL Server ၶႃႈ။ 
ၵူၺ်းၵႃႈ Database ၸိူဝ်းၼၼ်ႉ လူဝ်ႇလႆႈမီး "Server" (ၶိူင်ႈၸၢၵ်ႈလူင်) တွၼ်ႈတႃႇ Run မၼ်းၶႃႈ။

**SQLite** တႄႉ လၢၵ်ႇလၢႆးသေပိူၼ်ႈ လႄႈ ၵိုင်ႇငၢမ်ႇသုတ်း တွၼ်ႈတႃႇလုၵ်ႈႁဵၼ်းၶႃႈ:

1. **Serverless (ဢမ်ႇလူဝ်ႇ Server):** မၼ်းဢမ်ႇလူဝ်ႇ Install ပရူဝ်ႇၵႅမ်ႇ Server ယႂ်ႇလူင် လႃးလႃး။
2. **Single File (ၽၢႆႇလဵဝ်):** ၶေႃႈမုၼ်း Database တင်းသဵင်ႈ (Tables, Rows, Settings) တေထုၵ်ႇသိမ်းဝႆႉ ၼႂ်းၽၢႆႇ `.db` ဢမ်ႇၼၼ် `.sqlite` ဢၼ်လဵဝ်ၵူၺ်းၶႃႈ။
3. **Local Desktop Apps:** သၢင်ႇထုၵ်ႇသုတ်း တွၼ်ႈတႃႇ Desktop Application (မိူၼ်ၼင်ႇ Java Swing) ဢၼ်ႁဝ်းတေဢဝ် Program (File `.jar` သေ) ၵႂႃႇပၼ် User ၸႂ်ႉၼႂ်း Computer ၶဝ် ႁင်းၵူၺ်း ဢမ်ႇလူဝ်ႇလႆႈ ၵပ်းသိုပ်ႇလွင်ႈၼွၵ်ႈ (Internet) ၶႃႈ။

*(ၶေႃႈမၢႆတွင်း: Application ၼႂ်း Mobile Phone ၵမ်ႉၼမ် လႄႈ Web Browser တင်းသဵင်ႈ ၵေႃႈ ၸႂ်ႉ SQLite ပဵၼ်ပိုၼ်ႉထၢၼ်ၶႃႈ!)*

### 4. ၶိူင်ႈမိုဝ်း ဢၼ်ထုၵ်ႇလီမီး (DB Browser for SQLite)

ဢွၼ်တၢင်းႁဝ်း တေဢဝ် Java ၵႂႃႇသင်ႇ Database ၼၼ်ႉ၊ ႁဝ်းထုၵ်ႇလီ မီးၶိူင်ႈမိုဝ်း (Software) တွၼ်ႈတႃႇ ပိုတ်ႇတူၺ်း လႄႈ ၸၢမ်းၸႂ်ႉ Database ၼၼ်ႉ ႁင်းၵူၺ်း လွတ်ႈလွတ်ႈလႅဝ်းလႅဝ်း ဢွၼ်တၢင်းၶႃႈ။
ၼႂ်းၵႃႊ Software ၼမ်လၢႆၼၼ်ႉ လူတ်ႇလူင်းဢဝ် DB Browser သေ ၸႂ်ႉတိုဝ်းၶႃႈ။
